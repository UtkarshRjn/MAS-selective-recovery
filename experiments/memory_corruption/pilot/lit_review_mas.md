# Literature review: multi-agent memory, handoff, and safety (2024 to November 2026)

Search date: Saturday, November 21, 2026, Pacific Time. Every paper in the main table was opened at its official arXiv abstract page (and, where noted, a proceedings page). Nothing here is inferred from a title alone. Items not opened in this pass are listed at the end as unverified. A shorter companion note on handoff and diffusion of responsibility is in `prior_art_mas.md`.

This review is an internal planning file. It does not name people. It refers to the existing MAS selective recovery repository only as prior implementation work that this study can build on.

## What we already had from the earlier search

The earlier note verified MAST ([arXiv:2503.13657](https://arxiv.org/abs/2503.13657)) and the verifier-blind-spot theory note ([arXiv:2607.13918](https://arxiv.org/abs/2607.13918)), plus closest papers on handoff loss, diffusion of responsibility, and memory poisoning. This file adds failure taxonomies, error cascades, sycophancy, verifier placement, memory-poisoning attacks (AgentPoison, MINJA), recovery-related work, and MAS benchmarks (tau-bench, AgentDojo, MultiAgentBench).

## Recovery, checkpoint, and rollback

I did not find, in the pages I opened, a completed main-conference paper that already does selective recovery of damaged shared memory in a 3-role pipeline with irreversible tools. The existing MAS selective recovery repository is prior implementation work this study can build on (memory checks, recovery, and related gates). Official abstracts I did not open in this pass, and that should not be cited until they are fetched, include DART ([arXiv:2605.23311](https://arxiv.org/abs/2605.23311) appeared in search), SagaLLM ([arXiv:2503.11951](https://arxiv.org/abs/2503.11951) appeared in search), and a workshop PDF titled "Commit Before Trust." Treat those three as **unverified here**.

## Gap and hypothesis validation

Hypothesis 1. **Handoff loss.** Status: **partly shown**. Liu (2026), Sun et al. (2026), Li and Wang (2026), and Singh and Pawar (2026) already show that information, constraints, or checkable facts are lost or weakened between roles. What is still open is handoff loss of a *logged memory-damage flag* before an *irreversible* action, with F, T, and U damage in a shared MEMORY.md file.

Hypothesis 2. **Diffusion of responsibility.** Status: **partly shown**. Srinivasan et al. (2026) and Ying et al. (2026) show it for team safety and for delegated hazardous requests. It is **open** whether the same mechanism explains a pipeline that acts on damaged shared memory when a teammate already flagged it.

Hypothesis 3. **A verifier that reads raw memory and the profile beats a plan-only verifier.** Status: **open, with theory support**. Han (2026) predicts shared blind spots for same-family, same-evidence gates, and says a new evidence source is the lever. Singh and Pawar (2026) show that *when* and *on what* you verify matters. Nobody I found ran the exact P+V-plan vs P+V-raw contrast on damaged MEMORY.md.

Hypothesis 4. **Flags are raised but do not reach the actor.** Status: **partly shown** as a pattern (Sun et al., 2026; Li and Wang, 2026). **Open** as a logged-tool measurement (`flag(field, reason)`) on memory damage, with a funnel (damage present, flagged, flag reached the actor, harm, reported success).

Hypothesis 5. **A confirm-before-act rule is a useful fix, at a measured ask cost.** Status: **open in this setting**. Related mitigations exist (inspector and challenger in Huang et al., 2024; early gates in Singh and Pawar, 2026; a safety lead in Srinivasan et al., 2026), but not this frozen one-line memory confirm rule on irreversible tools, with a clean-run ask cost.

**Single strongest novel claim (tightly stated):** Holding the model and the damage cells fixed, a 3-role pipeline that shares one memory file can lose a logged notice between the agent that flags the damage and the agent that acts; a same-model verifier reduces silent irreversible harm only when it can read the raw memory and the profile, not when it sees only the plan.

This intersection was not found in the opened papers. A reviewer may still say the mechanism is a special case of Sun et al. or Li and Wang. The paper must distinguish the object (shared memory damage by visibility class), the action (irreversible tools), the logged flag, and the verifier-access test, and must not claim to have invented handoff loss or diffusion of responsibility as such.
