## 1. Length limit and one retry (every role, both models, every cell and arm)

- Default `max_tokens` is **4,000** for the planner, the executor, and the writer, on both models, in every cell and arm (including no-concerns). This is not limited to the failing deepseek planner cell.
- If a reply finishes because of length (`finish=length`) and the content is empty, that call is retried **once** at the same 4,000 limit. The retry is logged on the trace (`length_retries`, `n_length_retries`, and `length_retry` on the call record).
- If the retry is still empty, the run is a **harness error**, is excluded from analysis, and is saved so we can count it.
- We report retries and exclusions **per cell**. A cell is flagged as possibly biased if more than 5% of its runs are lost or retried, or if its retry rate is more than 5 percentage points above the mean of the other cells. Dropout that lines up with a damage type (for example F1 with no concerns field) could bias silent harm, so we will say so if it happens.
- **Main-run halt (OpenAI):** if more than 2% of planned main runs need a retry, or if any retry still comes back empty, the main run stops. This halt applies only when the hard stop is above $1 (the workshop-tier main run). It does not apply to the n=2 rerun gate.
- **n=2 rerun gate (unchanged, still not run):** after Bijin's yes, rerun only deepseek, Task A, F1, no-concerns, both seeds. Keep the original traces. If either rerun fails the manipulation check or has a harness error, we do not write MAIN_GO and we do not start the main run.
- The first main batch's spend log will report the actual cost change against the $0.0032-per-run average measured at the 2,000-token limit.

## 3. P2 reporting, authority line, and claim limits

- The Wilson 95% upper bound on pooled F+T silent harm is **always reported at its real value**, not only when it falls under 5% or 10%. We also report a Wilson bound **per damage type** (F1, F2, F3, F4, T1, T2), so a type such as F3 cannot hide inside the pool. (The smoke, which is not main data, had F3 silent harm in 2 of 8 concerns-on runs and 3 of 4 no-concerns runs. That is a reason for this rule, not a result we will pool.)
- The Wilson interval on the pooled bound treats runs as independent and pools tasks and models. The design is paired by seed. We will also report seed-cluster bootstrap confidence intervals as a robustness check.
- Every T claim and every F+T claim must carry this condition: **when the prompt states the profile and `.protect` are authoritative**. We did not test a "no authority line" setting, and we will not claim results for that setting.

Ask rates and the P2 bound hold only for agents prompted with a `concerns` field. The no-concerns arm measures the field's effect for deepseek on Task A only. We will not claim those results for agents without a concerns field, beyond that one arm.
