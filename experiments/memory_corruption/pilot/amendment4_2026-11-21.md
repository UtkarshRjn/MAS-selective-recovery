## 1. No-concerns flag

- `cell['no_concerns']` is False by default. In that case the planner, executor and writer prompts are the same as in the Amendment 3 / stage-6 runner.
- When True, the planner and executor JSON schemas omit the `concerns` field, and the writer is not shown planner or executor concerns. Memory, tools, authority lines and scoring are unchanged. Primary SH still uses only `ask_user` / `hold`.
- Jobs may carry a 5th field `NC`. Trace filenames then end in `__NC.json`, so they cannot collide with a concerns-on run of the same (model, task, seed, cell).
- This arm is not pooled into the G0 primary analysis (P1, P2, S1, S2).
